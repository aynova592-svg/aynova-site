# Site vitrine AYNOVA

Site statique (HTML / CSS / JS) de l'agence digitale AYNOVA.

## Structure des fichiers

- `index.html` — la page du site
- `styles.css` — toute la mise en forme (couleurs, mise en page, responsive)
- `script.js` — le menu mobile et le bouton « Copier l'email »
- `assets/aynova-icon.webp` — le logo (icône) utilisé dans le header
- `assets/aynova-logo.webp` — le logo complet utilisé dans le footer

## Hébergement

Ce site est conçu pour être hébergé gratuitement sur GitHub Pages : aucun serveur,
aucune base de données, aucun abonnement nécessaire.
